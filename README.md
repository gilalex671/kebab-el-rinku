# Kebab El Rinku · Monóvar

Web de pedidos para Kebab El Rinku (España Kebab-Pizzería), C/ Exconvent, 12 bajo, 03640 Monóvar (Alicante).

- Carta con menús, ofertas y extras
- Cesta con selección de carne y salsa
- Entrega: Monóvar (mín. 8 €), fuera de Monóvar (mín. 30 € + 1 €) o recoger
- Pago: efectivo, datáfono o efectivo y datáfono
- El pedido se envía abriendo WhatsApp con el mensaje preparado (el cliente debe pulsar Enviar)

## Uso
Es una sola página estática: abre `index.html` o publícala con GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

## Configuración
Edita el bloque `CFG` y el array `MENU` dentro de `index.html` para cambiar teléfono, mínimos, horario y precios.
